```typescript
    // Access control — GATE-04/GATE-05: check after auth succeeds
    // HEAD responses have no body — use X-Reason header (consistent with handler pattern)
    if (auth.pubkey) {
      const access = await checkAccess(storage, auth.pubkey);
      if (!access.allowed) {
        return new Response(null, {
          status: 403,
          headers: { "X-Reason": access.reason },
        });
      }
    }
```

This goes inside the `if (authHeader)` block, after `if (!auth.authorized)` returns. The `auth.pubkey` guard is needed because `validateAuth` types `pubkey` as optional. The `X-Reason` header is used instead of a JSON body because HEAD responses discard bodies per HTTP spec — this matches the existing pattern in `handleUploadCheck` where all errors use `X-Reason`.

**Do NOT modify** the no-auth path (when `authHeader` is null/absent). Without an auth header there is no pubkey to check. Unauthenticated preflight requests must still pass through to the size/hash checks.
