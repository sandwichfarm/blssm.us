4. Create src/middleware/price-feed.ts with these exports:
   - `loadPricingConfig(tomlPath: string): Promise<{ mints: string[]; pricing: PricingConfig }>` — parse TOML, validate mints (warn-and-skip invalid per existing pattern), validate pricing params (reject config if any invalid, return defaults). Default pricing: cost_per_gb_usd=0.02, margin=0.20, slippage=0.05.
   - `computeSatPrice(fileSizeBytes: number, btcUsdPrice: number, config: PricingConfig): number` — formula: `Math.max(1, Math.ceil((fileSizeGb * cost * (1+margin) * (1+slippage)) / btcUsd * 100_000_000))` where fileSizeGb = fileSizeBytes / (1024**3). 1 sat floor per user decision.
   - `fetchBtcUsdPrice(): Promise<number | null>` — fetch from CoinGecko (`https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd`) and Coinbase (`https://api.coinbase.com/v2/prices/BTC-USD/spot`) with `AbortSignal.timeout(5000)`. Use `Promise.allSettled`. Average both when available, single when one fails, null when both fail.
   - `startPriceFeedCron(pricePath: string): void` — calls fetchBtcUsdPrice(), writes `{ btc_usd: number, updated: number }` JSON to pricePath. Immediate first run, then `setInterval` every 5 minutes (300_000ms). Use setInterval, NOT Deno.cron (portability per research recommendation).
   - `readBtcUsdPrice(pricePath: string): Promise<number | null>` — reads the static JSON file written by cron. Returns btc_usd number or null if file missing/invalid. Handles both Deno.readTextFile and JSON.parse errors gracefully.

Import `parse` from `"@std/toml"`. Import `PricingConfig` type from `"../types.ts"`. Follow existing conventions: JSDoc on all exports, kebab-case filename, explicit .ts extension imports.

NOTE: The TOML config `[[mints]]` contains the mint URLs. The existing `config/payment.json` via Bunny Storage will remain for the PaymentConfig type from Phase 4 (amounts field). The TOML file is a LOCAL file on disk for pricing params and mint URLs for the new Phase 6 pricing system. Per research Pitfall 3 resolution: keep both, they serve different purposes.
