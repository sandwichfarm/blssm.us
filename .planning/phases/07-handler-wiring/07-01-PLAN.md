Create `src/middleware/payment-gate.ts` with a `paymentGate()` function modeled after `checkAccess()` in access.ts (self-contained, returns `Response | null`).

**Signature:**
```typescript
export async function paymentGate(
  request: Request,
  storage: StorageClient,
  fileSizeBytes: number,
): Promise<Response | null>
```

- Returns `null` = payment accepted (or payments disabled), handler proceeds
- Returns `Response` = 402 (no proof), 400 (bad proof), 503 (mint unreachable) — handler returns this directly

**Internal flow:**
1. `loadPaymentConfig(storage)` — get mints and amounts
2. `paymentsEnabled(config)` check — if false, return null (short-circuit)
3. `loadPricingConfig(PRICING_TOML_PATH)` — hardcode `const PRICING_TOML_PATH = "config/payment.toml"` as module constant (same hardcoding pattern as `PAYMENT_CACHE_TTL_MS` in payment-config.ts)
4. `readBtcUsdPrice(PRICE_PATH)` — hardcode `const PRICE_PATH = "/tmp/btc-price.json"` as module constant
5. If btcUsd is null, return null (fail open — avoids blocking users on startup race; mint still validates proofs cryptographically)
6. Extract `X-Cashu` header from request
7. If no X-Cashu header: call `buildPaymentRequired(fileSizeBytes, mintList, btcUsd, pricing)` and return the 402 Response
8. If X-Cashu header present: call `validateCashuPayment(cashuToken, mintList, requiredSats)` where `requiredSats = computeSatPrice(fileSizeBytes, btcUsd, pricing)` and `mintList = config.mints.map(m => m.url)`
9. If validation fails (`!result.valid`): return `buildPaymentError(result)`
10. If validation succeeds: return null

Add `/// <reference lib="deno.ns" />` at top (needed for readBtcUsdPrice which uses Deno.readTextFile).

**TDD approach:**
RED: Write tests first in payment-gate.test.ts covering:
- Payments disabled (empty mints) returns null
- No X-Cashu header returns 402 with X-Cashu response header and Cache-Control: no-store
- BTC price unavailable (null) returns null (fail open)
- Valid proof returns null
- Invalid proof returns 400 with X-Reason
- Mint unreachable returns 503 with Retry-After

Tests must mock `loadPaymentConfig`, `loadPricingConfig`, `readBtcUsdPrice`, `validateCashuPayment`, and `buildPaymentRequired` by using dependency injection OR by importing the real functions and mocking at the module level. Since Deno doesn't natively support module mocking easily, consider making paymentGate accept an optional `deps` parameter for test injection, or test against the real functions with controlled inputs (create a mock StorageClient that returns known payment config, write a temp price file, etc.). The simplest approach: use the real functions with a mock StorageClient and temp files.
