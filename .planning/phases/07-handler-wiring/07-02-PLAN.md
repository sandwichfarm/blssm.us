  <name>Task 2: Wire HEAD preflights with 402 pricing (no proof consumption)</name>
  <files>src/handlers/upload-check.ts</files>
  <action>
Replace the HEAD preflight stub 402 in upload-check.ts with real NUT-18 pricing. HEAD /upload and HEAD /media both route to handleUploadCheck (confirmed in router.ts).

**Critical constraint:** HEAD preflights must NEVER consume a Cashu proof. Even if the client sends an X-Cashu header on HEAD, ignore it silently. Do NOT call paymentGate() or validateCashuPayment(). Build the 402 directly with buildPaymentRequired().

1. Add imports at the top:
```typescript
import { loadPaymentConfig, paymentsEnabled } from "../middleware/payment-config.ts";
import { loadPricingConfig, readBtcUsdPrice } from "../middleware/price-feed.ts";
import { buildPaymentRequired } from "../middleware/payments.ts";
```

2. Replace the `if (access.requiresPayment)` block (lines 43-49) with:
```typescript
if (access.requiresPayment) {
  // HEAD preflights: always return 402, never validate X-Cashu
  // Even if client sends X-Cashu, ignore it — HEAD never consumes proofs
  const { config: payConfig } = await loadPaymentConfig(storage);
  if (paymentsEnabled(payConfig)) {
    const { pricing } = await loadPricingConfig("config/payment.toml");
    const btcUsd = await readBtcUsdPrice("/tmp/btc-price.json");
    if (btcUsd !== null) {
      // Use X-Content-Length for file size (BUD-06 convention for HEAD preflight)
      const sizeStr = request.headers.get("X-Content-Length");
      const effectiveSize = sizeStr ? parseInt(sizeStr, 10) : 0;
      const finalSize = isNaN(effectiveSize) ? 0 : effectiveSize;
      // 0 bytes → computeSatPrice returns 1 sat (floor), which is the minimum discoverable price
      const priceResp = buildPaymentRequired(finalSize, payConfig.mints.map(m => m.url), btcUsd, pricing);
      // HEAD response: copy headers, null body (HTTP HEAD spec)
      return new Response(null, {
        status: 402,
        headers: priceResp.headers,
      });
    }
  }
  // Payments disabled or price unavailable: fall through (fail open)
}
```

Key details:
- Uses `X-Content-Length` (not `Content-Length`) — BUD-06 HEAD preflight convention per RESEARCH.md Pitfall 2
- Unknown file size defaults to 0 → computeSatPrice returns 1 sat (honest minimum)
- Copies headers from buildPaymentRequired's response (X-Cashu, Cache-Control: no-store) but uses null body
- If payments disabled or BTC price unavailable, falls through (fail open matches paymentGate pattern)
- NO 411 for HEAD — missing X-Content-Length simply defaults to 0 (1-sat minimum price discovery, not a hard error)
