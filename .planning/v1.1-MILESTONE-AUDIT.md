**Root cause:** `loadCacheConfig()` from `src/middleware/cache-config.ts` has zero production call sites. Phase 5 added `ttlMs` parameters to `checkAccess()`, `loadPaymentConfig()`, and `isBlocked()` — but no handler or middleware calls `loadCacheConfig()` to read the operator's configured values. All three caches use hardcoded 60-second module constants.

**Fix scope:** ~10 lines — call `loadCacheConfig(storage)` in `paymentGate()` and/or handler files, pass returned values into existing `ttlMs` parameters.
